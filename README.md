# NexiHire – Job Portal System

NexiHire is a full-stack job portal application built with ASP.NET Core 9 that allows users to search for jobs, manage job opportunities, and securely interact with a modern recruitment platform.

This project is being developed as a real-world learning and portfolio application to strengthen enterprise software development skills using .NET technologies.

## Project Status

🚧 Currently in Development

This project is actively being built step by step and will continue to evolve with additional features, testing, and deployment improvements.

## Features (Planned & In Progress)

* User registration and authentication
* Secure login system using ASP.NET Identity
* Job search integration using the Adzuna API
* Job dashboard for viewing opportunities
* Save and manage jobs
* Apply button redirect to external job listings
* RESTful API architecture
* Swagger API documentation
* SQL Server database integration
* Automated API testing with xUnit
* Docker containerization

## Architecture Overview

NexiHire follows a layered architecture approach:

* MVC Frontend – User interface and interaction
* Web API – Backend services and API endpoints
* Entity Framework Core – Database management and ORM
* SQL Server – Data persistence
* Adzuna API – External job listing integration
* ASP.NET Identity – Authentication and authorization

## Getting Started

### Prerequisites

Before running the project, ensure you have installed:

* .NET 9 SDK
* SQL Server
* Visual Studio 2022 or VS Code
* Docker Desktop (optional)

### Clone the Repository

```bash
git clone https://github.com/yourusername/NexiHire.git
cd NexiHire
```

### Run the Project

1. Configure SQL Server connection strings.
2. Run Entity Framework migrations.
3. Start the API and MVC projects.
4. Open Swagger to test endpoints.
